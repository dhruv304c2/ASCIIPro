## Introduction
ASCIIPRO a 2D ASCII art/Text game engine with ASCII rendering and a 2D Physics


#### Supported Platforms
Windows

#### Features (Planned)
- 2D Physics
- ASCII sprites sheets (as .txt files)
- Sprite Animations
- Audio system
- Particle system

## Getting Started

#### Dependencies
make sure you have
- clang
- make
- cmake
- Ninja (For default build process)

### Default build process

Use following command on the project root directory

```
    make 
```
final build would be found in the /build/game/bin as game.exe file

### Building using Visual studio

#### Generate visual studio solution

```
    cmake -G "Visual Studio 17 2022" .
```

#### Build with visual studio
 
 Once you have generated a visual studio solution files open the project through visual studio IDE and build from there
